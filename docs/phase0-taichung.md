# Phase 0 盤點報告：臺中市（2026-11-03）

## 結論
臺中可以直接用「**市府建物圖 × GIS 門牌點位**」做空間比對，免費資料就能把 **93.8%** 的門牌對到地上樓層數，同時帶出房屋型態和結構。原方案的三維建物模型和 TGOS 在臺中都**不需要**。

## 來源盤點結果

| 來源 | 狀態 | 重點 |

## 空間比對結果（`scripts/phase0_taichung.py`）
- 門牌點落在建物多邊形內：1,160,947（86.9%）
- 落在多邊形外、但 10m 內有建物：91,737（6.9%）
- **合計可對應：93.8%**；各行政區介於 73%（6601400）到 99.9%（中區）
- 已知問題：
  - 31,337 棟建物的樓層數是 0，影響 7,478 筆門牌。
  - 一棟建物最多對到 1,161 個門牌（大樓分戶門牌），這是正常情況。
- 抽樣結果合理，例如「市政路 390 號」對到 50 層、「富榮街 38 之 2 號十四樓」對到 16 層大廈。
- 產出檔：`data/phase0_addr_floor.parquet`（全部比對結果）、`data/phase0_sample.csv`

## 風險與待確認
1. **準確率還沒驗證**：要用實價登錄的「總樓層數」當答案比對。
2. 裙樓＋塔樓：門牌點可能落在低樓層的裙樓多邊形，造成樓層低估。
3. 鄉區涵蓋率較低（73%～88%），沒對到的可以放寬距離，或用實價登錄補。
4. 建物圖的「更新年度」不等於屋齡；屋齡和地下層數要靠實價登錄或使照補。

## 另外發現（全台擴充時用得到）
- 臺北市建築執照套繪圖 SHP（data.gov.tw #151936）有 `bud_floor`（樓層）、`bud_const`（構造），臺北可以套同樣的做法。
- 推測其他縣市可能也有類似的建物圖，要逐一盤點。
