# Phase 1 全國驗證（2026-11-10）

`scripts/validate_phase1.py` 產生。用網站實際的查詢邏輯做**留一驗證**：每縣市從有實價登錄的門牌抽 2,000 個
（共 42,050 個）當答案，把這些門牌自己的實價拿掉、同棟推估表重算、人工校正不用，再查一次，看推估的地上總樓層對不對。

**限制**：答案只能來自有實價的門牌（以公寓、大樓為主），沒有買賣紀錄的透天、老屋準確率可能較低；
有實價的門牌在正式網站會直接用自己的實價（信心「高」），所以下表量的是「門牌沒有實價時」的推估準確率。

## 總結

- 有回傳樓層：69.1%；完全相符 86.5%、差一層內 95.2%
- 信心「高」：完全相符 96.0%（目標 ≥ 95%）
- 正式網站涵蓋率（全部門牌抽樣 40,878 個）：高 21.7%、中 18.8%、低 13.9%、無 45.6%
